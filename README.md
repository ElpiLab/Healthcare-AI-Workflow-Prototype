# Healthcare-AI-Workflow-Prototype

## Neue UI-Demo: Einwilligungsablauf

`consent-flow.html` zeigt einen interaktiven 5-Screen-Prototyp für den RxFlow-Einwilligungsablauf:

1. Zweck und Kontrolle erklären
2. Verwendete Daten auswählen
3. Zugriffsberechtigte Personen transparent machen
4. Einwilligung prüfen und bestätigen
5. Erfolgreiche Speicherung mit Audit-Informationen

Die Demo ist standalone und kann direkt im Browser geöffnet werden.
